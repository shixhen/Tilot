# 上下文与技能

## 添加 Skills

- 全局技能放在 `~/.tilot/skills/<目录名>/SKILL.md`。Windows 下对应 `%USERPROFILE%\.tilot\skills`。普通对话和项目对话都能使用。
- 项目技能放在项目根目录的 `skills/<目录名>/SKILL.md`。同名时使用项目技能，名称以文件里的 `name` 为准。

已有技能可以将整个目录复制到对应位置。新建技能时，用 UTF-8 保存如下格式的 `SKILL.md`。

```markdown
---
name: review-code
description: 检查当前项目的代码改动与潜在问题
---

这里是技能正文。需要使用该技能时，模型通过 read 工具读取。
```

打开对话后，可以发送「使用 review-code 技能检查这次修改」。Tilot 在每次模型请求前刷新技能索引，提供 `name`、`description` 和路径。全局技能使用绝对路径，项目技能使用项目相对路径。正文由模型通过 `read` 按需读取，执行脚本仍受该对话的工具权限控制。

## 加载规则

- 全局技能的元数据有误时跳过该项，并在对话中提示路径和原因。全局目录内的同名技能一并跳过，通知列出冲突路径。同一问题每轮只提示一次。
- 项目技能格式错误或项目内名称重复时，本次请求报错。单份 YAML 元数据最多 64 KiB，技能子目录链接跳过，目录或文件链接沿用现有校验。
- 项目根目录的 `AGENTS.md` 全文追加到系统指令。项目技能和指令以打开的项目根目录为范围，用户主目录用于加载全局 Skills。

## 上下文压缩

- 输入框发送独立的 `/compact` 可手动压缩。运行中会先停止当前轮次，等工具结果保存后开始压缩。压缩完成后等待用户继续，已有等待消息保持暂停。
- 每次生成前估算即将发送的指令、历史、工具声明和图片。达到模型设置容量的 90% 时自动压缩。未单独设置的模型使用 666,000 Token，触发点是 599,400 Token。上下文图标展示最近一次请求的输入估算。服务商用量继续用于请求统计和费用。
- 压缩用摘要替换旧上下文，保留预算内的近期用户原话。轮内优先完整保留当前输入及最新一组工具结果。空间仍不足时，缩短发给模型的工具结果文字，保留调用和结果的配对。原始聊天与工具历史继续可以查看。
- 摘要按历史组分批处理，过大的工具组按调用和配对结果分批。若摘要请求在生成前也被服务拒绝为上下文超限，则减少较早的摘要输入后重试。
- 模型服务在生成前明确报告上下文超限时，Tilot 尝试压缩并重试该请求一次。若无法腾出空间，或者自动压缩失败，本轮结束并显示原因，上次成功摘要继续可用。

Responses 请求继续使用模型服务默认的输出上限。

## 代码入口

- `packages/context/src/project.ts`：根指令、技能元数据读取及指令组合。
- `packages/context/src/context.ts`：从压缩检查点构建后续上下文并校验工具调用与结果配对。
- `packages/context/src/compaction.ts`、`packages/context/src/request.ts`：组织摘要输入，估算请求并按上下文预算调整工具结果。
- `packages/context/src/prompts.ts`：读取内置 UTF-8 Markdown 提示词，正文存放在 `packages/context/prompts/`。
- `packages/agent-core/src/run-turn.ts`：调度压缩和超限重试，保存请求状态并继续轮次。

YAML 使用 [yaml 库](https://eemeli.org/yaml/) 解析，支持带引号的字符串和多行描述，不自行实现 YAML 语法。
# 中断历史

启动服务时取得数据目录排他锁，再将遗留的运行中轮次和模型请求标记为 interrupted。保留原输入、已完成响应和已保存工具结果。仅对 interrupted 轮次中缺失的工具结果，在模型上下文里补充 status: unknown 的配对说明，数据库仍保留空结果；其他不完整记录继续报错。

桌面仅在最新轮次已中断时显示“继续任务”。turn.resume 创建新的轮次，保留原记录不变，由模型先核实项目状态。不会恢复旧执行栈、自动重放旧工具调用或生成摘要。正常停止和正常关闭服务仍记为 cancelled。

系统、项目和恢复提示词正文维护在 `packages/context/prompts/*.md`，不再建立独立的提示词工作区包。文件用途与修改方式见 [Context 说明](../packages/context/README.md)。工具及参数的描述直接写在 packages/tool 的工具声明中。

系统提示词每轮开始读取一次，轮内固定，修改在下一轮生效，无需重启。默认系统提示词附带按宿主时区计算的轮次开始日期和时区，供模型解析相对日期。系统提示词或日期变化可能影响其后的缓存复用。项目根指令和技能索引继续按每次模型请求加载。
