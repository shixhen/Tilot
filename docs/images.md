# 图片输入与恢复

用户图片和工具图片均遵循 Responses API，不按模型名称分支、不自动切换模型。支持 PNG、JPEG、WebP，按实际字节识别。保存并发送原图，不主动缩放、压缩、截断，也不增加图片张数或大小业务上限；文件、网络和模型服务的错误按实际原因显示。

## 使用方式

- 输入框左下角加号菜单包含上传图片、新建对话和选择项目。支持多文件选择、拖入对话区和剪贴板图片粘贴，图片先加入草稿，不提前发给模型服务。
- 网页拖来的图片元素或网址列表会下载为附件；普通粘贴网址仍是文字。
- 支持图文、多图和纯图消息。添加顺序不因导入先后完成而改变。成功图片可以先发送，失败或仍在导入的附件留在输入框，失败项可以重试或移除。
- 草稿、等待区、用户历史和工具输出展示缩略图，点击在应用内预览，支持缩放、复位和拖动。缩略图只从本地服务读取已保存副本，不直接请求来源网站。
- 助手正文中的 Markdown 图片支持本地绝对路径、本机 `file:///` 地址和 HTTP(S) 图片网址。进入可见区域时加载缩略图，点击缩略图打开应用内预览。右键选择「复制图片地址」可以复制来源网址或本地路径。
- `view_image({path})` 读取本地图片，`view_image({url})` 读取 HTTP(S) 图片；两者互斥。所有权限模式均可读，允许项目外的路径。相对路径使用当前对话工作目录。

## 图片保存与模型上下文

原图存入应用数据目录的 `images`，按 SHA-256 内容寻址并原子写入；随对话长期保留，不纳入命令日志和网页缓存的过期清理。网络图片使用现有代理、重定向、取消机制，总下载超时 30 秒，图片不沿用网页文本的 2 MiB 下载上限。

SQLite 用户输入保存轻量的 `ImageRef`，包含内容标识、文件名、实际 MIME 与字节数。内部历史使用 `tilot-image:` 引用；每次请求在 Context 构建后读取并校验副本，转换为标准 `input_image` 数据 URL，再交给 SDK。用户消息的内容数组保留文字与图片的顺序；纯图消息不补默认文字。工具结果使用标准 `function_call_output.output` 内容数组，文本和真实图片一起进入后续请求。图片副本缺失或损坏会明确失败，不忽略图片后继续请求。

取消、失败、异常退出沿用原有恢复规则。已保存的用户图片、完整输出与真实工具结果保留，未执行的工具不补跑；模型不接受图片时保留用户历史并显示 API 错误。

## MCP 图片

支持工具返回的直接 `image`、内嵌二进制图片资源，以及明确提供的图片 `resource_link`。资源链接优先通过同一 MCP 连接读取；没有资源读取能力时，HTTP(S) 图片链接使用网络下载。不增加通用资源浏览或提示词模板功能。

某张图片获取失败时，保留其他图片、原工具文本和结构化 JSON，并附上具体失败原因。工具已经返回，不为了重新取图自动重跑原工具。MCP 原权限不变：只读不加载，项目内修改逐条审批，完全访问直接执行。资源读取和取图属于这次调用，计入原来的调用超时。

## 草稿、等待队列与去重

桌面本地存储按对话保存图文草稿，保存的图片是应用数据副本引用。仍未完成导入的本地文件或网络地址可以重试；尚未保存成功的剪贴板／拖拽文件在重启后需要重新添加，不伪装成已保存的图片。

整个等待队列（包括纯文字）持久保存，重启后先暂停。恢复时向服务查询投递回执，移除已经被接收的消息，剩余消息由用户点击继续；引导和普通启动共用稳定的 `deliveryId`。SQLite 唯一约束和服务端核对保证同一投递重试返回原记录，内容不一致时拒绝复用身份，不重开轮次或重跑工具。

草稿转入队列前先记录交付身份，覆盖“已经入队、尚未清空草稿时退出”的窗口。恢复同时检查本地队列和服务回执，避免一份内容同时留在草稿和等待区。失败附件、未投递内容与交付期间新增的内容继续保留。模型运行中的图片引导仍等下一次模型请求，不打断当前生成或工具；答案优先和暂停规则保持原行为。

数据库版本 14 增加输入的图片引用，版本 15 增加投递身份；自动迁移旧文字输入、权限、问题及模型历史。

## 接口和验证边界

| RPC | 参数 | 结果 |
| --- | --- | --- |
| `image.import` | `{path}`、`{url}` 或 `{base64, name}` | `ImageRef` |
| `image.read` | `{imageId}` | `{image, dataUrl}` |
| `input.receipts` | `{deliveryIds, threadId?}` | 已接收的投递标识 |
| `turn.start` | `{threadId, input, images?, deliveryId?}` | 原有 `Turn` |
| `turn.steer` | `{turnId, input, images?, deliveryId?}` | 原有 `TurnInput` 或 `null` |

图片导入和读取独立处理，不阻塞停止、引导和审批请求。服务关闭时取消未完成的图片 I/O，并等待其收尾再关闭存储。

本地测试覆盖原图副本、重启及迁移、Responses 实际请求体、取消和损坏图片、MCP 三种图片来源及局部失败、图文队列回执、草稿交接、文件／网页拖拽解析、粘贴、上传菜单和预览操作。未调用真实付费模型或第三方 MCP，也未启动原生桌面窗口；Windows 文件选择器、真实拖拽与剪贴板，以及模型服务的实际视觉能力仍需桌面验收。
