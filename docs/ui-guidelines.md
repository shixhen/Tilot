# Tilot UI 规范

## 基准

采用 [shadcn sidebar-07](https://ui.shadcn.com/blocks/sidebar#sidebar-07) 的页面与侧栏组合，保留默认 Neutral 深色主题。大体使用 Codex 的任务侧栏、对话正文、底部输入结构，不再复刻截图中的具体颜色和尺寸。

遵循 [官方主题规范](https://ui.shadcn.com/docs/theming) 和 [Sidebar 组合规范](https://ui.shadcn.com/docs/components/sidebar)。官方也提供 [shadcn 技能](https://ui.shadcn.com/docs/skills)，本项目当前采用其公开规范，没有安装额外全局技能。

## 约束

- 优先使用 `components/ui` 中的官方组件；页面组合在 `workspace`，业务状态在 hooks。不得把旧页面作为新页面的包装层。
- 颜色只使用 background、card、muted、accent、border 等语义变量。禁止独立蓝色气泡、渐变侧栏、逐组件硬编码颜色。
- 字号：正文与导航 14px，辅助文案 12px，空状态标题 24px。布局使用 Tailwind 默认间距，常用 8、16、24、32px。
- 圆角、按钮高度、表单边框和焦点样式沿用官方默认值；不通过全局选择器覆盖组件内部结构。
- 图标只用 Lucide，图标按钮必须有中文可访问名称；只展示真实可用的功能。
- 使用官方 Sidebar 的响应式抽屉与 Dialog 的焦点管理。桌面、窄窗口、长任务名、长代码块均需核对溢出。
- Markdown 样式只约束模型内容，不控制应用布局；不执行 HTML，不自动请求模型图片。
- 默认只做代码及编译检查，界面由开发人员验收；未经要求不启动预览或桌面进程。

## Windows 原生材质

Windows 11 桌面窗口启用深色主题及 Mica，使用自定义标题栏将侧栏开关固定在最左侧。窗口控制按钮通过 Tauri 调用最小化、最大化/还原与关闭，空白区域支持拖动和双击最大化。WebView、标题栏和桌面侧栏底层透明，透出同一个系统背景；中央对话面板、设置弹窗和窄窗口抽屉仍使用实色主题。浏览器不展示桌面窗口控制，不模拟系统材质。Mica 外观及窗口行为需在桌面程序中验收。

侧栏与正文位移统一使用 240ms、`cubic-bezier(0.2, 0, 0, 1)`，先快后慢、不回弹；遵循系统减少动态效果设置。对话标题区不再重复放置侧栏开关。

桌面侧栏默认 240px，可拖动右侧边缘调整；最小 200px，最大 480px 且不超过窗口的一半。向内拖过最小宽度立即收起，但保持指针捕获，按住鼠标向外拖回阈值即可重新展开。收起状态下松开，再通过按钮展开时恢复这次拖动前的宽度。拖动时关闭布局过渡，直接跟随指针；宽度在当前窗口会话中保留。拖动边缘悬停只改变鼠标光标，不显示高亮；键盘聚焦保留可见提示，左右方向键每次调整 16px。窄窗口仍使用模板抽屉。

## 模板适配边界

消息操作栏：用户消息只在悬停或键盘聚焦时显示时间、复制和编辑；编辑将原文放回输入框，发送时新建轮次，保留旧历史。AI 正文常驻复制与统计图标，时间仅在悬停或聚焦时显示。操作栏预留高度，避免悬停导致对话跳动；不加入评价或分支按钮。

统计浮层展示该回复所属模型请求的数据，不合计整轮多个请求。首 token 耗时从请求发起算到首个非空正文、推理、拒绝或工具参数增量；TPS = 服务端输出 token / 首增量到请求结束的秒数，不计工具时间。token 用量使用响应 usage 原值，缓存命中包含在输入中。计时自数据库版本 7 起保存；历史或服务端缺失值显示“暂无数据”，不估算或补零。多条消息属于同一请求时共享该请求统计。

保留 SidebarProvider、SidebarInset、SidebarHeader/Content/Footer 及可折叠菜单结构。将示例团队切换、账户资料、项目链接替换为本地工作区、真实任务和连接设置；模板内容占位块替换为对话和 Card 输入区。基础组件来自官方 New York v4 注册表，保留 MIT 许可；仅移除未使用的辅助组件、改为独立 Radix 包导入，并补充注释与中文无障碍文案。

对话正文与输入框共用最大 752px 的居中容器，两侧各留 16px，正文和输入框最大宽度均为 720px，随可用空间同步伸缩。统一修改 workspace/page.tsx 中的 column 常量即可调整两者宽度。滚动区域使用 scrollbar-gutter: stable both-edges 在左右两侧对称预留滚动条空间，避免内容由短变长时横向跳动，并保持正文和输入框视觉居中。
