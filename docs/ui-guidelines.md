# Tilot UI 规范

## 基准

采用 [shadcn sidebar-07](https://ui.shadcn.com/blocks/sidebar#sidebar-07) 的页面与侧栏组合，保留默认 Neutral 深色主题。大体使用 Codex 的任务侧栏、对话正文、底部输入结构，不再复刻截图中的具体颜色和尺寸。

遵循 [官方主题规范](https://ui.shadcn.com/docs/theming) 和 [Sidebar 组合规范](https://ui.shadcn.com/docs/components/sidebar)。官方也提供 [shadcn 技能](https://ui.shadcn.com/docs/skills)，本项目当前采用其公开规范，没有安装额外全局技能。

## 约束

- 优先使用 `components/ui` 中的官方组件；页面组合在 `workspace`，业务状态在 hooks。不得把旧页面作为新页面的包装层。
- 颜色只使用 background、card、muted、accent、border 等语义变量。禁止独立蓝色气泡、渐变侧栏、逐组件硬编码颜色。
- 界面字体使用 system-ui，由系统选择默认 UI 字体，正文、侧栏和输入控件统一继承；代码使用等宽字体，公式使用 KaTeX 数学字体。
- 字号：正文与导航共用 text-sm（默认 14px），辅助文案 12px，空状态标题 24px。Markdown 正文与列表行高为 1.5 倍；一级、二级、三级标题为 20、17、15px，代码为 12.5px，公式随正文相对缩放；以阅读层级和视觉协调为准，不要求精确等比例。布局使用 Tailwind 默认间距，常用 8、16、24、32px。
- 圆角、按钮高度、表单边框和焦点样式沿用官方默认值；不通过全局选择器覆盖组件内部结构。
- 图标只用 Lucide，图标按钮必须有中文可访问名称；只展示真实可用的功能。
- 使用官方 Sidebar 的响应式抽屉与 Dialog 的焦点管理。桌面、窄窗口、长任务名、长代码块均需核对溢出。
- Markdown 样式只约束模型内容，不控制应用布局；不执行 HTML，不自动请求模型图片。
- 默认只做代码及编译检查，界面由开发人员验收；未经要求不启动预览或桌面进程。

## Windows 原生材质

Windows 11 桌面窗口启用深色主题及 Mica，使用自定义标题栏将侧栏开关固定在最左侧。窗口控制按钮通过 Tauri 调用最小化、最大化/还原与关闭，空白区域支持拖动和双击最大化。WebView、标题栏和桌面侧栏底层透明，透出同一个系统背景；中央对话面板、设置弹窗和窄窗口抽屉仍使用实色主题。浏览器不展示桌面窗口控制，不模拟系统材质。Mica 外观及窗口行为需在桌面程序中验收。

侧栏与正文位移统一使用 200ms、`cubic-bezier(0.2, 0, 0, 1)`，先快后慢、不回弹；遵循系统减少动态效果设置。对话标题区不再重复放置侧栏开关。

桌面侧栏默认 240px，可拖动右侧边缘调整；最小 200px，最大 480px 且不超过窗口的一半。向内拖过最小宽度立即收起，但保持指针捕获，按住鼠标向外拖回阈值即可重新展开。收起状态下松开，再通过按钮展开时恢复这次拖动前的宽度。拖动时关闭布局过渡，直接跟随指针；宽度在当前窗口会话中保留。拖动边缘悬停只改变鼠标光标，不显示高亮；键盘聚焦保留可见提示，左右方向键每次调整 16px。窄窗口仍使用模板抽屉。

## 模板适配边界

用户消息发送后立即提供操作栏，在悬停或键盘聚焦时显示时间、复制和编辑；编辑将原文放回输入框，发送时新建轮次，保留旧历史。AI 正文在所属轮次结束后常驻复制与统计图标，时间仅在悬停或聚焦时显示。运行中不挂载 AI 消息操作图标，也不能通过悬停或键盘聚焦查看统计；保留操作栏高度，避免结束时消息跳动。已结束轮次的操作不受其他正在运行的轮次影响；失败、取消和中断也算结束。不加入评价或分支按钮。

每段思考与每次工具调用的标题显示耗时，运行中实时更新，结束后读取持久化的实测时间。思考从该段首个非空推理增量计到结束，不包含首 token 等待；工具只计实际执行，不包含排队或模型生成参数的时间。未执行的工具不显示耗时，旧记录缺少数据时显示“耗时未知”。数据库版本 10 保存各段思考和通用工具计时，不修改模型原始响应或工具结果。

整个轮次的过程、单段思考、工具调用和侧栏分组共用 200ms 高度过渡，后续元素随展开、收起连续移动；内外间距和边框也参与折叠，支持嵌套与中途反向切换，遵循系统减少动态效果设置。收起内容不可被键盘或辅助技术访问，关闭动画结束后卸载内容。

工具详情只显示输入和实际输出，名称、状态和耗时保留在标题。网页仅显示正文，不附加网页标题、来源或抓取时间；其他工具也不附加数量、缓存标识、续读位置等说明。编辑输出保留差异着色，目录和搜索输出保留路径、类型、行号及空结果，失败保留错误原文。完整元数据继续保存并返回模型，不因界面简化而影响缓存续读或执行上下文。

统计浮层标题为“本轮模型请求”，累计当前轮次内所有模型请求，展示模型请求次数、首 token 耗时、生成速度、缓存命中率、缓存命中/未命中及输出 token，不显示总 token。推理、正文及工具调用生成按接口 usage 计入；工具结果作为下一次请求的输入计入，工具执行本身不额外计 Token。成功、失败、截断、取消或中断请求已返回的用量均参与汇总，同一请求的多条消息及工具卡片不重复计数。

首 token 耗时从轮次开始算到首次非空正文、推理、拒绝或工具参数增量。TPS = 累计输出 token / 各次模型生成时间之和，其中每次生成时间为请求耗时减去首 token 等待，不含工具执行时间，不平均各次 TPS。缓存命中率 = 累计 cached_tokens / 累计 input_tokens × 100%，四舍五入至整数，不平均各次百分比；缓存未命中为累计输入减累计缓存命中。每次请求重复发送的历史上下文仍按该次 usage 计入输入，不按唯一消息去重。输入为零或缺少必要用量时显示“暂无数据”。

运行中持续采集请求数据，当前轮次的统计入口在整轮结束后出现；某次请求缺少用量时，受影响的合计显示“暂无数据”并说明缺失请求数，不以部分和冒充完整数据。计时自数据库版本 7 起保存；旧计时缺失时不估算。历史重新打开后从全部分页的原始请求记录重新计算；同轮消息共享本轮累计，失败轮次没有正文时也有统计入口。用量汇总使用独立函数，未来整个对话的统计可复用原始请求集合，目前不提供对话总统计。

保留 SidebarProvider、SidebarInset、SidebarHeader/Content/Footer 及可折叠菜单结构。将示例团队切换、账户资料、项目链接替换为本地工作区、真实任务和连接设置；模板内容占位块替换为对话和 Card 输入区。基础组件来自官方 New York v4 注册表，保留 MIT 许可；仅移除未使用的辅助组件、改为独立 Radix 包导入，并补充注释与中文无障碍文案。

对话正文与输入框共用最大 752px 的居中容器，两侧各留 16px，正文和输入框最大宽度均为 720px，随可用空间同步伸缩。统一修改 workspace/page.tsx 中的 column 常量即可调整两者宽度。滚动区域使用 scrollbar-gutter: stable both-edges 在左右两侧对称预留滚动条空间，避免内容由短变长时横向跳动，并保持正文和输入框视觉居中。
