# 异步提问

内置 `request_user_input_async` 在普通、项目对话及所有权限模式中开放。描述放在工具声明中，提问不授予其他工具权限。工具登记成功立即返回，不等待答案；Agent 继续完成不依赖答案的工作，没有独立工作时结束本轮。

## 填写与提交

- 每组至少一题，不限制题数；每题 0–4 个纯文字选项，可指定一个推荐项，推荐项在界面置顶。
- 题目和选项均按普通文字显示。每题始终有多行文字输入框，选项与文字答案互斥。选项切换后保留文字草稿，再次进入文字框可恢复。
- 输入框上方逐题展示；点击选项自动下一题，最后一题停留。默认高亮第一项不算回答。Enter 换行，Ctrl+Enter 确认本题，末题可提交整组。
- 可上一题、下一题或明确跳过；最后一题直接提交，不增加总览页。每题都回答或明确跳过后才能整组提交，全部跳过也可以提交。
- 卡片最高约半个窗口，正文内部滚动，操作栏固定；显示题号但不提供跳题菜单。不抢普通输入框焦点，不提供数字快捷键。
- 同时出现审批时两者都可见，审批更靠近普通输入框。

每个对话最多一组待回答问题，由数据库唯一索引和执行层共同保证。旧组未提交或关闭时，新的提问调用收到明确错误，不覆盖旧组。不同对话互不影响，工具声明不因待回答状态变化而增删。

运行中提交的整组答案作为引导进入同一轮的下一次模型请求，不中断当前模型或工具；空闲时开启新轮次。答案优先于尚未开始的普通等待消息，已开始的启动请求先收尾，原队列暂停状态保持不变。

问题在历史中保留为可展开的工具条目，答案显示为一条完整展开的普通用户消息，逐题列出问题、答案或已跳过。上下文保留组标识，历史展示隐藏机器标识；通过 `user_questions.inputId` 关联真实用户输入。

## 保存、关闭和恢复

数据库版本 13 增加 `user_questions`，保存问题、当前题号、每题选项、文字草稿及处理状态。只读权限不限制这些应用内部记录。

每次编辑先写桌面本地草稿，在线时合并后串行同步到 SQLite；断连仍可编辑，不能提交，重新连接并加载对话后同步。正常保存不显示提示，错误在卡片内展示并可重试。停止、请求失败、进程退出和普通消息均不会清除待回答问题。未提交草稿不进入模型上下文。

关闭表示放弃整组待回答状态，不触发模型；有已填写内容时确认，空白时直接关闭。历史记录保留，之后允许新提问。提交后不原地修改，通过普通消息更正。

提交答案与追加输入／创建轮次在同一 SQLite 事务中完成；重复提交相同答案返回原投递，不重复开轮，不重跑旧工具。停止收尾期间提交会报告错误并保留草稿，可稍后重试。模型请求失败仍保留已正式提交的答案和真实轮次状态。

## 实现与验证

- `packages/tool/src/request-user-input.ts`：声明、参数校验与宿主调用。
- `packages/store/src/questions.ts`：唯一待答组、草稿、关闭及原子提交。
- `packages/server/src/turn-manager.ts`：引导或启动轮次，投递身份及事件。
- `apps/desktop/src/questions.ts`：离线草稿、串行保存、重试与恢复。
- `apps/desktop/src/workspace/question-panel.tsx`：使用官方 `@shadcn/react/questionnaire`，组合现有 shadcn Card、Button、Textarea、Dialog；沿用现有主题。

组件参考 [官方 Questionnaire](https://ui.shadcn.com/docs/components/radix/questionnaire)。自动跳题、多行输入与持久保存按本项目规则适配。

本地测试覆盖真实 SDK 流、Server 行协议、SQLite 重开、重复提交、只读提问、停止保留、离线保存、队列优先级以及 DOM 逐题交互。不调用真实付费模型，不启动浏览器预览或桌面窗口；原生窗口视觉效果仍由开发人员验收。
