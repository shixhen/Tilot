# 产品需求文档

更新日期：2026-10-02

## 1. 定位与范围

Tilot 是 Windows 桌面编程 Agent，以 DeepSeek 为主要模型，主对话只支持 Responses API。工具设计参考 Pi，已实现 read、write、edit、shell、ls、find、grep 七个本地工具和 web_fetch 网页读取。项目对话开放全部八个，普通对话仅开放 web_fetch；网络搜索按开发者要求暂缓，规格及进度见 [工具重写计划](tool-rewrite-plan.md)。

任务可绑定用户选择的项目，文件工具面向源代码及相关文本配置。ls 列目录，find 查文件名，grep 搜索内容；shell 使用 PowerShell，以项目目录为初始工作目录，继续承担 Git、测试、构建和其他开发命令。不另建 Git 或 Office 专用工具。

## 2. 核心功能

| 功能 | 行为 |
| --- | --- |
| 打开项目 | 选择本地目录，首次发送时固定绑定任务，显示项目名称及路径 |
| 读取代码 | 按文件和行范围读取，回答中引用路径及行号 |
| 列目录与搜索代码 | ls 非递归列目录，find 按 glob 查文件，grep 返回匹配路径、行号及可选上下文；可继续 read |
| 写入文件 | write 写入完整文件内容，用于新建或重写 |
| 修改文件 | edit 精确替换指定文本，匹配有歧义时报告错误 |
| 执行命令 | shell 通过 PowerShell 执行命令，返回输出及退出状态，支持取消、超时和输出限制 |
| 读取网页 | web_fetch 匿名读取公开 HTTP(S) 网页，HTML 转 Markdown，返回来源与抓取时间，缓存支持行分页及长行续读 |
| 对话与历史 | 流式回答、任务切换、继续、补充需求、取消 |

find/grep 使用 rg 的忽略规则，搜索隐藏文件但排除 .git，不跟随内部链接；显式指定文件的 grep 直接搜索该文件。结果使用项目相对路径并标记截断。开发阶段使用本机 rg，正式打包时内置固定版本；缺少 rg 明确报错，其他工具仍可执行，不自动下载或切换搜索语义。

shell 首版使用 Windows 自带 PowerShell 5.1，每次启动独立进程，以项目根目录为初始工作目录；不加载个人配置、不提供交互输入或长期后台服务。开发者已确认默认运行 5 分钟，可指定 1～600 秒；输出保留末尾 50 KiB，并标记截断。超时或取消终止进程树，终止失败明确报告。脚本及输出统一 UTF-8，外部命令自行输出其他编码时不自动猜测转换。

开发者要求执行体验沿用 Codex；依据已提供截图中的“完全访问”模式，采用直接执行命令和修改文件、展示执行过程与结果和差异的方式，不逐次弹出批准窗口，取代原先固定批次的修改提案流程。用户可以取消运行；直接执行不表示自动重试已发生副作用的操作。首版不自行增加权限模式切换界面。

## 3. 界面与文件访问约定

界面布局、功能入口与交互以 Codex 为参照，按已提供截图分批实现；截图未覆盖的界面先与开发者确认。不增加侧栏文件树或独立文件浏览器。模型通过工具列目录、读取和搜索项目文件，与界面展示相互独立。

选择项目根目录时解析其真实路径。文件、目录和搜索工具使用项目内相对路径，拒绝跟随内部符号链接及 Windows 目录联接；ls 只可列出链接名称和类型。shell 的工作目录不构成访问隔离，不能声称上述路径检查会约束 PowerShell 的文件、进程或网络访问。无项目任务不提供本地工具，可使用 web_fetch 读取网页。

web_fetch 不需要搜索服务或额外模型密钥。用于公开网页，拒绝非公开 IP 和本地域名，30 秒总超时、最多 5 次重定向，下载/解压/转换正文各限 2 MiB；默认 200 行，正文每次最多 50 KiB，缓存仅归当前任务，保留 7 天并受总容量回收。网页来源与抓取时间固定，续读不重新联网。不执行 JavaScript、不提供登录态、不解析 PDF，不将网页文字视为新指令。网络层自动使用宿主代理环境与 NO_PROXY 规则，没有额外开关；直连检查并固定 DNS 地址，代理模式由可信宿主代理负责目标解析和连接。

文件读取支持 UTF-8（含 BOM），以 LF 或 CRLF 分行并保留原始换行，移除文件开头的 BOM；offset 从 1 开始，默认 200 行，显式最多 2,000 行，正文最多 50 KiB。项目文件只返回完整行，提供 nextOffset 续读；单行超过上限明确报错。按块检查实际读取部分的 UTF-8 编码及二进制控制字符，不预先扫描整个文件。命令日志另可按 outputId 读取，超长行用 byteOffset 分段续读。界面中命令执行、结果及文件差异的展示继续参考 Codex。

参考：[Pi 默认工具实现](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/tools/index.ts)。参考其基础工具划分，不引入整套 Pi 框架。
