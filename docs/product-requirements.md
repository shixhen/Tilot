# 产品需求文档

更新日期：2026-09-20

## 1. 定位与范围

Tilot 是 Windows 桌面编程 Agent，以 DeepSeek 为主要模型，只支持 Responses API。工具设计参考 Pi，首版保留 read、write、edit、shell 四个基础工具。

任务绑定用户选择的项目，文件工具面向源代码及相关文本配置。shell 使用 PowerShell，以项目目录为初始工作目录，用于查看目录、搜索及执行开发命令。不另建目录枚举、搜索、Git、Office 或网页专用工具。

## 2. 核心功能

| 功能 | 行为 |
| --- | --- |
| 打开项目 | 选择本地目录，首次发送时固定绑定任务，显示项目名称及路径 |
| 读取代码 | 按文件和行范围读取，回答中引用路径及行号 |
| 搜索代码 | 模型通过 shell 调用命令搜索文件名或文本 |
| 写入文件 | write 写入完整文件内容，用于新建或重写 |
| 修改文件 | edit 精确替换指定文本，匹配有歧义时报告错误 |
| 执行命令 | shell 通过 PowerShell 执行命令，返回输出及退出状态，支持取消、超时和输出限制 |
| 对话与历史 | 流式回答、任务切换、继续、补充需求、取消 |

目录遍历和搜索的过滤由所调用命令及参数决定，不再自行开发统一目录枚举和忽略引擎。具体命令是否可用取决于机器已安装的工具，缺失时应报告实际错误。

shell 首版使用 Windows 自带 PowerShell 5.1，每次启动独立进程，以项目根目录为初始工作目录；不加载个人配置、不提供交互输入或长期后台服务。开发者已确认默认运行 5 分钟，可指定 1～600 秒；输出保留末尾 50 KiB，并标记截断。超时或取消终止进程树，终止失败明确报告。脚本及输出统一 UTF-8，外部命令自行输出其他编码时不自动猜测转换。

开发者要求执行体验沿用 Codex；依据已提供截图中的“完全访问”模式，采用直接执行命令和修改文件、展示执行过程与结果和差异的方式，不逐次弹出批准窗口，取代原先固定批次的修改提案流程。用户可以取消运行；直接执行不表示自动重试已发生副作用的操作。首版不自行增加权限模式切换界面。

## 3. 界面与文件访问约定

界面布局、功能入口与交互以 Codex 为参照，按已提供截图分批实现；截图未覆盖的界面先与开发者确认。不增加侧栏文件树或独立文件浏览器。模型通过工具列目录、读取和搜索项目文件，与界面展示相互独立。

选择项目根目录时解析其真实路径。read、write、edit 使用项目内相对路径，拒绝内部符号链接及 Windows 目录联接。shell 的工作目录不构成访问隔离，不能声称上述路径检查会约束 PowerShell 的文件、进程或网络访问。无项目任务暂不提供这四个工具。

文件读取已确认支持 UTF-8（含 BOM），以 LF 或 CRLF 分行并保留原始换行，移除文件开头的 BOM；offset 从 1 开始，单次默认且最多 200 行，正文最多 50 KiB。只返回完整行，提供 nextOffset 续读；单行超过上限时明确报错。按块检查实际读取部分的 UTF-8 编码及二进制控制字符，不预先扫描整个文件，也不把该检查当成完整文件格式识别。界面中命令执行、结果及文件差异的展示继续参考 Codex。

参考：[Pi 默认工具实现](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/tools/index.ts)。参考其基础工具划分，不引入整套 Pi 框架。
