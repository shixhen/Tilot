# 产品需求文档

更新日期：2026-09-18

## 1. 定位与范围

Tilot 是 Windows 桌面 Agent，当前阶段仅实现代码文件的读取、搜索、新建与修改，以 DeepSeek 为主要模型，只支持Responses API。

操作范围为用户选择的项目目录，支持源代码及相关文本配置文件。二进制文件、表格、Office、网页、命令执行、Git 操作和文件批量整理不纳入本期，也不列入后续版本计划。

## 2. 核心功能

| 功能 | 行为 |
| --- | --- |
| 打开项目 | 选择本地目录，展示文件树与访问范围 |
| 读取代码 | 按文件和行范围读取，回答中引用路径及行号 |
| 搜索代码 | 在项目内搜索文件名或文本，返回匹配位置 |
| 新建文件 | 在现有目录生成新代码文件，目标已存在时报告冲突 |
| 修改文件 | 基于已读取版本生成修改，展示差异后应用 |
| 对话与历史 | 流式回答、任务切换、继续、补充需求、取消 |

读取与搜索遵守项目忽略规则，默认排除版本控制目录、依赖目录和生成目录。新增或修改文件统一经过差异预览；用户确认固定批次后执行，不逐文件重复询问。
