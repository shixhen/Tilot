# 产品方案

适用版本：v0.1

## 1. 定位与范围

Tilot 是 Windows 桌面 Agent，当前阶段仅实现代码文件的读取、搜索、新建与修改，以 DeepSeek 为主要模型。

操作范围为用户选择的项目目录，支持源代码及相关文本配置文件。二进制文件、表格、Office、网页、命令执行、Git 操作和文件批量整理不纳入本期，也不列入后续版本计划。

## 2. 核心功能

| 功能 | 行为 |
| --- | --- |
| 打开项目 | 选择本地目录，展示文件树与访问范围 |
| 读取代码 | 按文件和行范围读取，回答中引用路径及行号 |
| 搜索代码 | 在项目内搜索文件名或文本，返回匹配位置 |
| 新建文件 | 在现有目录生成新代码文件，目标已存在时报告冲突 |
| 修改文件 | 基于已读取版本生成修改，展示差异后应用 |
| 对话与历史 | 流式回答、任务切换、继续、补充需求、取消 |
| 修改记录 | 保存前后版本和结果，支持有冲突检查的撤销 |

读取与搜索遵守项目忽略规则，默认排除版本控制目录、依赖目录和生成目录。新增或修改文件统一经过差异预览；用户确认固定批次后执行，不逐文件重复询问。

## 3. 使用流程

1. 选择项目目录并配置 DeepSeek API Key。
2. 输入需求，模型读取或搜索相关代码。
3. 展示拟新增文件和修改差异。
4. 用户确认后写入，核对文件内容并记录结果。
5. 输出修改摘要及文件定位。

应用不执行项目代码、构建或测试。结果说明仅报告实际文件变更，不声明编译通过或功能测试通过。

## 4. 界面

| 区域 | 内容 |
| --- | --- |
| 左侧 | 项目、文件树、任务历史 |
| 中间 | 对话、读取/搜索活动、取消与继续 |
| 右侧 | 带行号的代码视图、修改差异、应用与撤销 |

首版提供代码查看和差异审阅，不建设完整 IDE。采用中文界面，支持键盘操作与 125%/150% 缩放。

## 5. 执行交互

| 操作 | 规则 |
| --- | --- |
| 读取、搜索 | 在授权项目内直接执行 |
| 新建、修改 | 确认差异后写入；参数或文件变化使确认失效 |
| 补充需求 | 当前工具批次结束后生效 |
| 停止 | 取消模型请求，停止派发新工具；保留已提交修改 |
| 继续 | 新建执行批次，先核对上次未确定的写入 |
| 撤销 | 仅在当前内容匹配修改后指纹时恢复 |
| 关闭窗口 | 活跃任务停止后退出；异常重启不自动继续 |

配置 Key 时说明代码内容会按需发送至 DeepSeek。任务历史与修改备份保存在本地。任务随应用运行，关闭应用后不继续执行；异常中断后先核对文件再继续。

## 6. 验收目标

目标环境：Windows 11 x64、普通用户权限、16 GB 内存、SSD。数值为设计目标，待原型测量。

| 项目 | 要求 |
| --- | --- |
| 首次可交互 | ≤ 5 秒，网络等待除外 |
| 停止反馈 | ≤ 200 ms 显示停止中；结果未知的操作单列 |
| 文本兼容 | UTF-8、中文/空格路径，保留既有 BOM 与换行风格 |
| 写入正确性 | 差异与落盘内容一致；提交前检测到版本变化时拒绝写入 |
| 恢复 | 重启后可查已提交消息、修改和备份，不重复写入 |
| 分发 | Windows x64 安装包，用户无需安装开发工具链 |

并发外部编辑的竞态限制见 [技术设计](03-technical-design.md#5-修改取消与恢复)；安装依赖与测试要求见 [开发计划](05-roadmap-and-validation.md)。
