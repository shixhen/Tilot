# 模型提示词

项目内维护的模型提示词统一放在 `@tilot/prompts` 工作区包中，由 `src/index.ts` 统一导出。Server、Context 和 Tool 声明此包依赖后按包名导入，不跨目录访问源码。本包仅包含提示词常量，不依赖其他业务包，无需复制文本资源。

- `src/system.ts`：正式系统策略，包含协作方式、工具使用、技能使用和恢复约束。
- `src/tools.ts`：四个基础工具及参数的自然语言说明；参数结构仍由 Tool 定义。
- `src/project.ts`：项目指令和技能元数据的包装说明。
- `src/recovery.ts`：继续任务时的输入，以及未保存工具结果的未知状态说明。

Server 统一提供系统策略，桌面不传入系统提示词。Context 在此基础上加入项目根目录 AGENTS.md 和技能元数据。项目自己维护的 AGENTS.md、.codex/skills 下的 SKILL.md 仍保留在项目内，不复制到这里。

未知工具结果只用于构造合法且诚实的模型上下文，不会写成数据库中的执行结果。继续任务创建新轮次，不自动重跑旧调用；模型需先核实状态，不能将未保存结果理解为未执行。
